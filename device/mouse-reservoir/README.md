# Mouse-shaped water reservoir

3D-printable water reservoir for the IVC cage, shaped like a mouse.

| File | Part |
|---|---|
| `mouse_reservoir_body.stl` | Reservoir body |
| `mouse_lid.stl` | Lid (top cap + plug body) |
| `color_paint_guide.png` | 4-colour paint guide for the slicer |

## Multicolour printing (4 slots)

Import both STLs, select the body, use the Color Paint tool:

- Brown (slot 1): body, everything not listed below
- Beige (slot 2): belly oval, muzzle oval, 2 feet pads
- Black (slot 3): 2 eye domes, nose dome
- Pink (slot 4): 2 inner ear ovals
- Lid: top cap brown, plug body beige
